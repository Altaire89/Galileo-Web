### Instalar dependencias backend:
cd backend

Backend en python. Debes instalar las dependencias de "requirements.txt" por primera vez.

python -m pip install -r requirements.txt

### Ejecutar backend:
python3 main.py

### Instalar dependencias forntend:
cd frontend

Frontend en Next.js. Debes instalar las dependencias de "package.json" y demás por primera vez.

npm install

### Ejecutar backend:
npm run dev
